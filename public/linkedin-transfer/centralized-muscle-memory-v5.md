An agentic setup can work beautifully… right until a fresh install turns it into terminal archaeology. 🏺

My answer is simple: keep the genuinely useful bits in one version-controlled place.

Not because every agent should become identical. Quite the opposite. The point is to make good capabilities easy to reuse, inspect and remove when they stop earning their place.

Less drift. Fewer unpleasant surprises. A setup that survives a reset without dragging every old experiment back from the dead. 🤷

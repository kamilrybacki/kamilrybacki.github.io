USER GUIDE

See what your agents called.

Use the admin panel, audit log, and Prometheus metrics.

On this page
  • Sign in
  • Admin views
  • Prometheus metrics
  • Phone notifications

The admin application normally listens on port 8789. Sign in with the administrator token.

Sign in

Open /admin/login on the admin origin. The browser uses a session cookie. API clients can send the administrator bearer token.

Admin views

ViewUse
/admin/Tool configuration and status.
/admin/profilesProfile manifests.
AuditRecent decisions.
ApprovalsPending operations and learned grants.

Prometheus metrics

Scrape /metrics on the admin port. Configure server.metrics_token_env for a separate metrics bearer token if required. Process counters can reset on restart.

Phone notifications

Configure the optional PWA and Web Push with SPLICEDOCK_VAPID_PUBLIC_KEY, SPLICEDOCK_VAPID_PRIVATE_KEY, and SPLICEDOCK_VAPID_SUBJECT. Strong approvals still follow the WebAuthn policy.

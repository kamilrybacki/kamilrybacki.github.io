USER GUIDE

Keep backend credentials in the gateway.

Use stored or short-lived credentials to reach a backend.

On this page
  • Credential selection
  • Existing secret
  • Issue credentials on demand

The agent uses a profile token. Splicedock selects the backend credential for the call.

Credential selection

Splicedock checks the profile binding, the deployment defaults, and the backend configuration in that order.

Existing secret

Declare gh first and set the referenced variable on the gateway. Use an environment or Vault reference to keep the raw secret out of the YAML.

Issue credentials on demand

Define a provider in credential_providers and refer to it with mint in the profile. On first use the broker requests a credential, caches it, and refreshes it before expiry. Choose the backend credential’s minimum required scope.

The server must define the named github-app provider. It can run a configured helper that returns a GitHub App installation token.

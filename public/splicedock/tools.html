USER GUIDE

Bring your tools to one endpoint.

Connect MCP, HTTP and CLI backends.

On this page
  • Choose a driver
  • MCP server
  • HTTP endpoint
  • CLI passthrough
  • Fixed CLI command

Choose a driver for the system you are integrating and add its exposed names to the appropriate profiles.

Choose a driver

DriverUse it for
mcp_proxyAn existing MCP server.
httpOne HTTP API operation.
cliA fixed executable and argument template.
cli_passthroughA CLI whose argument array needs policy checks.

MCP server

Add this entry under tools: in your configuration.

Supply a hostname and port. The driver constructs an HTTP URL ending in /mcp or /sse, depending on transport.

HTTP endpoint

Add this entry under tools: in your configuration.

Allow demo__health in the profile. Configure request parameters and authentication in the tool definition.

CLI passthrough

Allow the executable in server.cli_whitelist and configure per-command rules. The driver exposes help and run tools. The run tool accepts an args array and optional cwd in the gateway environment.

After configuring the gh backend, call gh__run with these arguments.

Fixed CLI command

The quickstart uses a fixed cli tool. Use passthrough when you need rules on an argument array.

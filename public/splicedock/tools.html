04 / backendy

MCP, HTTP i CLI za wspólną bramką.

Cztery typy backendów: serwer MCP, HTTP API, stałe polecenie CLI i CLI passthrough.

Na tej stronie
  • Wybór drivera
  • Serwer MCP
  • Endpoint HTTP
  • CLI passthrough
  • Stałe polecenie CLI

Wybierz driver według tego, co integrujesz. Profile pracują na nazwach wystawionych narzędzi.

Wybór drivera

TypKiedy użyćNazwa narzędzia
mcp_proxyUsługa już udostępnia MCP.Nazwa backendu + nazwa narzędzia upstream.
httpChcesz opakować pojedynczy endpoint API.namespace__name
cliChcesz wystawić ustalone polecenie i jego parametry.namespace__name
cli_passthroughChcesz wywoływać CLI tablicą argumentów i stosować reguły argv.name__help oraz name__run

Serwer MCP

Podaj host bez schematu i ścieżki oraz port swojego serwera. Driver buduje adres HTTP z końcówką /mcp albo /sse; ten przykład dotyczy połączenia wewnątrz zaufanej sieci. Do zewnętrznego backendu HTTPS potrzebny jest odpowiednio skonfigurowany pośrednik. Jeśli narzędzie nie pojawia się w katalogu, sprawdź połączenie upstream, uwierzytelnianie oraz wzorce profilu. Poświadczenia odkrywania katalogu pochodzą z konfiguracji backendu; późniejsze wywołania mogą użyć nadpisania profilu.

Endpoint HTTP

Profil musi dopuszczać demo__health. Parametry deklarujesz w params, z miejscem path, query, body lub header. Dla auth dobierz poświadczenia bramki zamiast żądać ich od agenta przy każdym wywołaniu.

CLI passthrough

To fragment do połączenia z resztą konfiguracji. CLI musi być dostępne w środowisku bramki. Przekaż GH_TOKEN do procesu serwera; dopuszczaj go do procesu narzędzia tylko tam, gdzie jest potrzebny.

args jest tablicą, nie poleceniem shella. Opcjonalne cwd wskazuje katalog roboczy w środowisku bramki, nie na komputerze klienta. Dla CLI z wbudowaną tabelą komend nieznane podkomendy są domyślnie odrzucane; niezależne twarde ograniczenia, np. brokerska ścieżka operacji GitHub, pozostają w mocy.

Stałe polecenie CLI

Przykład demo__version ze szybkiego startu używa drivera cli. Nie jest zamiennikiem policy engine dla dowolnych poleceń. Reguły argv i approvale opisane w tej dokumentacji dotyczą cli_passthrough.

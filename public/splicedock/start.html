USER GUIDE

From configuration to your first call.

Run Splicedock locally with Node.js 22 and one read-only tool.

On this page
  • 1. Prepare the environment
  • 2. Save the configuration
  • 3. Start the application
  • 4. Create a token and connect a client

This example exposes the installed Node.js version. It needs no external backend.

1. Prepare the environment

Install Git, Node.js 22, and npm. Install dependencies under the same Node version that runs the gateway so the native SQLite module is compatible.

2. Save the configuration

Save this as splicedock.local.yaml or download the example. The demo profile exposes only the version tool. The example disables strong consent for this local read-only demo.

3. Start the application

The MCP endpoint is http://127.0.0.1:8788/mcp. The admin port is 8789. Keep the administrator token available for the next step.

4. Create a token and connect a client

Create a demo profile token, then configure your MCP client with the endpoint and bearer token.

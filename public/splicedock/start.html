USER GUIDE

From configuration to your first call.

Start Splicedock locally, authenticate, and verify your first tool result.

On this page
  • 1. Prepare the environment
  • 2. Save the configuration
  • 3. Start the application
  • 4. Make your first tool call
  • 5. Stop the demo

This example exposes the installed Node.js version. It needs no external backend.

1. Prepare the environment

Install Git, Node.js 22, and npm. Install dependencies under the same Node version that runs the gateway so the native SQLite module is compatible.

2. Save the configuration

Copy the demo configuration from the checkout. The demo profile exposes demo__version and enables Code Mode. The example disables strong consent for this read-only demo.

View the example configuration

3. Start the application

Run the next command in the same terminal so it can use the administrator token. The gateway serves MCP on port 8788 and the Admin API on 8789. For this example use a local machine with those ports available.

4. Make your first tool call

The example issues a short-lived profile token, lists tools, and calls demo__version over MCP.

The version should match node --version in the same terminal. The example revokes its token when it finishes. To connect your own client, create a separate profile token.

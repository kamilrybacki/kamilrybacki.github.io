03 / katalog narzędzi

Profil określa, co agent może zobaczyć i wywołać.

Wybierz katalog narzędzi, włącz Code Mode i edytuj profile w WebUI bez utraty komentarzy.

Na tej stronie
  • Manifest profilu
  • Edycja w przeglądarce
  • Rewizje i konflikty zapisu
  • Co dzieje się po restarcie
  • API manifestów

Profil zawiera listę wzorców narzędzi, flagę Code Mode i opcjonalne poświadczenia dla backendów.

Manifest profilu

Przy tworzeniu nowego profilu dodaj name: demo. W edytorze istniejącego profilu nazwa wynika z wybranego wpisu i nie jest częścią manifestu.

tools musi mieć co najmniej jeden element. Profile obsługują wzorce glob, np. gh__*. Nie myl ich z filtrami katalogu ustawianymi osobno przez konkretnego klienta MCP.

Flaga wbudowanego narzędzia

enable_code_mode domyślnie jest wyłączone. Ani "*", ani wpisanie nazwy executora na listę tools nie włącza Code Mode.

Edycja w przeglądarce

  1. Otwórz /admin/profiles i wybierz profil z katalogu.
  2. Zmień YAML. Użyj validate, aby sprawdzić składnię i schemat.
  3. Zapisz przyciskiem save lub skrótem Ctrl/Cmd + S.
  4. Po zmianie listy narzędzi odśwież katalog w kliencie MCP.

Możesz utworzyć profil, zduplikować istniejący, usunąć go lub wyeksportować katalog. Edytor ostrzega przed opuszczeniem niezapisanych zmian. Komentarze i formatowanie tekstu manifestu pozostają w bazie.

Rewizje i konflikty zapisu

Każdy dokument ma rewizję. Zapis wysyła base_revision. Jeżeli dokument zdążył się zmienić, API odpowiada 409 i zwraca aktualną wersję. Porównaj ją z własnymi zmianami, przeładuj dokument i ponów świadomie zapis.

422 oznacza błąd walidacji. Nieznane pola, niewłaściwe typy i niedozwolone klucze obiektu są odrzucane; pojedynczy manifest ma limit 64 KiB.

Co dzieje się po restarcie

Konfiguracja YAML uzupełnia brakujące profile przy starcie. Po zapisaniu katalog w bazie jest źródłem aktualnego stanu. Restart nie nadpisuje edycji z WebUI, a jawnie usunięty profil nie jest odtwarzany z konfiguracji. Repliki korzystające ze wspólnego Postgresa synchronizują katalog.

Po zmianie sekretu lub katalogu sprawdź kolejne wywołanie. Zmiana profilu nie cofa skutków już uruchomionej operacji.

UtworzeniePOST /api/v1/profiles/manifest, JSON z tekstem manifest zawierającym nazwę

USER GUIDE

Give each agent a tool catalog.

Configure the tool catalog, Code Mode, and credential bindings.

On this page
  • Profile manifest
  • Edit in the browser
  • Revisions and conflicts
  • Storage and restart
  • Manifest API

A profile limits the names a client can discover and call. Tool policies still apply to individual calls.

Profile manifest

Use exact tool names or globs. A new manifest includes name. Code Mode has an explicit flag and is disabled by default.

Edit in the browser

Open /admin/profiles, select a profile, edit the YAML, and save. The editor validates the document and retains its comments.

Revisions and conflicts

Saves include base_revision. If somebody else has saved since you opened the editor, HTTP 409 asks you to reload and reconcile the changes.

Storage and restart

YAML configuration seeds missing profiles at startup. The catalog keeps committed manifests in the database. A deleted configuration profile stays deleted across restarts.

Manifest API

List profiles with GET /api/v1/profiles. Request the YAML catalog with ?format=yaml. Use the profile editor for revision-aware updates.

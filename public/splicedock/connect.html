Use an MCP client that supports Streamable HTTP and an Authorization header.

Two kinds of token

TokenPurpose
AdministratorManage profiles, tokens, and approvals.
ProfileAuthenticate an MCP client and select its permitted tools.

Create a profile token

Create the demo profile first. Run the following with your administrator token.

HTTP 201 returns data.token and data.id. Save the raw token in your client’s secret store when it is issued.

Configure the client

The exact configuration field names depend on your client. Reconnect after changing them.

How the profile is selected

A valid bearer token selects its bound profile. Use a profile token and a URL without query parameters. The ?profile= parameter is deprecated. Set server.require_profile_token: true to reject tokenless clients. An unknown, expired, or revoked token returns HTTP 401.

Rotate or revoke a token

ActionEndpoint
List tokensGET /api/v1/profile-tokens
RotatePOST /api/v1/profile-tokens/:id/rotate
RevokePOST /api/v1/profile-tokens/:id/revoke with reason manual or compromised

Update the client after rotation. Admin UI mutations using a session cookie require X-Splicedock-CSRF.

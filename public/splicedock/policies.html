CLI passthrough checks the argument array before starting a process.

Evaluation order

The gateway checks the argument limit, deny rules, allow rules, and required arguments before handling approval. A hard denial takes precedence.

Policy example

Request and consume approval

The tool returns approval_id and expires_at. Wait through approvals__wait for up to 120 seconds per call. After approval, submit the same operation with the same token, profile, argument array, and resolved working directory before expiry. Each approval can be used once.

Strong approval with WebAuthn

Set server.consent.rp_id, its HTTPS origin, and the trusted hardware attestation roots. Configure the public origin used by the browser.

Optional learned grants

Enable SPLICEDOCK_GRANTS=1 to permit eligible operations after repeated successful approvals in similar contexts. Review or revoke grants in the admin panel.

USER GUIDE

Trace a problem to its source.

Diagnose common connection, catalog, policy, YAML, and runtime errors.

On this page
  • MCP returns HTTP 401
  • Missing tool or empty catalog
  • Denied by policy or broker_required
  • Approval did not start the operation
  • YAML save returns 409 or 422
  • Application fails to start
  • Code Mode timed out
  • Report a problem

Start with the HTTP status or tool error and check the active profile.

MCP returns HTTP 401

Check the profile bearer token, expiry, and revocation status. Use the MCP endpoint and a Streamable HTTP client.

Missing tool or empty catalog

Check the token’s profile, tool name and profile patterns. Refresh the client catalog after edits. Code Mode must be enabled explicitly.

Denied by policy or broker_required

Read the rule named in the tool result. A hard denial requires a policy change or a different permitted operation. Use the applicable broker for operations it owns.

Approval did not start the operation

Retry the exact operation after approval and before expiry. Keep your token, profile, arguments, and working directory the same.

YAML save returns 409 or 422

For 409, reload the manifest and reconcile concurrent edits. For 422, fix the reported YAML or schema error.

Application fails to start

Check the configured HTTPS consent origin and RP ID, SQLite write permissions, and the Node.js version used to install native modules. Use a shared PostgreSQL database for multiple replicas.

Code Mode timed out

Reduce the number of calls and the result size. Check the call summary before retrying because a tool may already have completed.

Report a problem

Include the version, runtime, tool name, error, and a redacted configuration excerpt. Keep credentials and private payloads out of the report.

HTTP 401 przy połączeniu MCP

Sprawdź Bearera, termin ważności i odwołanie tokenu profilu. Upewnij się, że nie używasz tokenu administracyjnego ani tokenu scrape. Gdy require_profile_token jest włączone, parametr ?profile= nie zastępuje tokenu.

Pusty katalog albo brak narzędzia

  1. Sprawdź profil przypisany do tokenu.
  2. Porównaj pełną nazwę narzędzia z wzorcami w tools.
  3. Sprawdź dostępność CLI, whitelistę albo połączenie i auth upstream.
  4. Sprawdź filtr katalogu w samym kliencie i połącz go ponownie.

Brak Code Mode oznacza zwykle brak enable_code_mode: true. Sama gwiazdka nie wystarczy.

Denied by policy albo broker_required

Odczytaj nazwę reguły. Twarda odmowa nie jest oczekiwaniem na zgodę i nie zniknie po ponowieniu. Zmień żądaną operację albo poproś administratora o świadomą zmianę konfiguracji. broker_required wskazuje osobną, dedykowaną ścieżkę wrażliwej operacji, nie awarię CLI.

Zgoda nie uruchamia operacji

Po zatwierdzeniu trzeba ponowić tę samą operację przed expires_at. Zachowaj token, profil, argumenty i cwd. Zgoda może być już wykorzystana lub wygasła. Wywołujący bez tokenu profilu nie może utworzyć ani użyć zgody.

Zapis YAML: 409 albo 422

409: dokument zmienił się od odczytu. Porównaj aktualną wersję i rewizję. 422: popraw składnię albo schemat. Nowy profil wymaga name, istniejący dokument — nie. tools nie może być puste.

Aplikacja nie startuje

Jeżeli błąd wskazuje consent.rp_id lub consent.origin, skonfiguruj domenę HTTPS dla silnej zgody. Lokalny przykład odczytu jawnie ją wyłącza. Przy błędzie SQLite użyj zgodnego Node 22 i zainstaluj zależności w tym runtime; npm ci uruchomione inną wersją Node może zbudować niezgodny moduł natywny.

Sprawdź też zapisywalny CELLARETTE_DB_PATH. Domyślna ścieżka systemowa może być niedostępna dla zwykłego użytkownika. Dla wielu replik użyj wspólnego Postgresa, nie osobnych plików SQLite.

Timeout Code Mode

Zwróć mniejszy wynik, ogranicz liczbę kroków i unikaj pętli bez końca. Odczytaj calls. Przed ponowieniem sprawdź, które operacje mogły się wykonać — timeout nie cofa skutków.

Zgłoszenie problemu

Do zgłoszenia dołącz wersję, runtime, nazwę narzędzia, kod błędu i zredagowany fragment konfiguracji. Usuń tokeny, wartości sekretów, argumenty zawierające dane wrażliwe i prywatne adresy. Repozytorium projektu.

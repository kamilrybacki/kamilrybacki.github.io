Run a workflow

Set the code argument on code_mode__execute. This example uses the quickstart.

Discover and call tools

APIReturns
tools.list()Names and descriptions.
tools.search(query)Matching tools and schemas.
await tools.call(name, args)An MCP tool result.

Use Promise.all to run independent reads concurrently. Check isError and use the backend’s actual response shape.

Sandbox and limits

ResourceLimit
Input and final result64 KiB each
VM memory / stack16 MiB / 512 KiB
JS execution turn / workflow1 s / 30 s
Tool calls / concurrent calls50 / 4
Tool response4 MiB

The QuickJS runtime has no direct filesystem, network, process, module loader, or timers. Code Mode cannot invoke itself.

Simulate operations before execution

Preflight prepares each HTTP request, MCP call, or CLI command and obtains a fixture from a local simulator. The reviewer receives the snippet and trace. In enforcement mode, the gateway checks each live operation against the approved trace before sending or running it.

Observe mode stops at review. Use enforce mode with a trusted review service that independently enforces operation permissions. A model score alone cannot authorize an operation. Use a profile token. HTTP, fixed CLI, CLI passthrough, and already connected Streamable HTTP MCP are supported. CLI passthrough applies its ordinary live policy and approvals. SSE is unsupported. Traffic produced inside a CLI process or remote MCP backend is outside this check.

Errors, approvals, and retries

Check each tool result and await all started operations. A later failure, timeout, or a changed preflight trace cannot roll back a call that has already started. A separate retry for an approved operation must obey the original policy.

README / dla użytkownika

Jeden toolbox dla wszystkich agentów.

Jeden endpoint MCP dla serwerów narzędzi, HTTP API i CLI. Profile, reguły, zgody i Code Mode.

Na tej stronie
  • Jedna droga do narzędzi
  • Co możesz z tym zrobić

Połącz agenta z jedną bramką. Udostępnij mu potrzebne narzędzia i zarządzaj dostępem w jednym miejscu.

01 / START

Pierwsze narzędzie

Uruchom lokalny przykład, wystaw odczyt wersji Node i wykonaj pierwszy workflow.

02 / MCP

Podłącz agenta

Utwórz token profilu i użyj go w kliencie Streamable HTTP.

Jedna droga do narzędzi

AgentCellaretteMCP / HTTP / CLI

Bramka wybiera katalog narzędzi według profilu. Przy wywołaniu dobiera backend i poświadczenia. Dla CLI passthrough sprawdza reguły na argumentach, a operacje objęte zgodą przekazuje do decyzji człowieka.

Co możesz z tym zrobić

  • Połączyć różne typy backendów za jednym interfejsem MCP.
  • Ograniczyć katalog profilu i zarządzać jego manifestem YAML.
  • Sprawdzać polecenia CLI przed startem, odmawiać albo prosić o zgodę.
  • Dobrać poświadczenia po stronie bramki, także osobno dla profilu.
  • Wykonać workflow w JavaScript i zwrócić modelowi potrzebny fragment wyniku.
  • Sprawdzić audyt, metryki i zgody w panelu administracyjnym.

Gdzie przebiega granica

Reguły bramki obejmują wywołania, które przez nią przechodzą. Natywny shell, pliki lokalne i inne narzędzia agenta wymagają własnych ograniczeń. Profil wybiera narzędzia; nie nadaje automatycznie uprawnień w systemie backendu.

Najkrótsza droga: lokalny przykład, potem token i klient MCP.
